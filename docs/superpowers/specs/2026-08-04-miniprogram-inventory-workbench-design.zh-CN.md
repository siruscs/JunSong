# 小程序库存工作台视觉统一设计

## 目标

以首页核算周期页面为唯一视觉基准，统一库存查询、库存流水、库存调整三个页面的视觉和交互层级，使店长、主管可以快速识别当前部门、库存状态和可执行动作。

## 范围

- `pages/stock/index.vue`：库存查询
- `pages/stock-ledger/index.vue`：库存流水
- `pages/stock-adjustment/index.vue`：库存调整
- 复用现有 `StateView`、权限、部门上下文、字典缓存和请求接口。

## 设计约束

1. 不修改数据库、接口契约、权限码、幂等键、草稿逻辑和库存业务状态机。
2. 不改变库存金额、数量、成本和部门过滤的计算口径。
3. 保留当前页面入口和核心操作，只优化布局、层级、反馈和窄屏适配。
4. 保持小程序原生组件和现有样式体系，不新增 UI 依赖。

## 页面设计

### 统一视觉基准

- 顶部使用核算周期首页同款浅蓝渐变头部、部门标签和标题副标题。
- 指标使用核算周期首页同款浮起 KPI 卡片，采用白底、细边框、低饱和状态色和轻阴影。
- 内容使用核算周期首页同款 `section-card`、`section-header`、圆点标识、标题和辅助链接。
- 页面背景、间距、边框、阴影和数字层级与首页保持一致，不再使用独立的实心蓝色库存头部。

### 库存查询

- 使用统一业务头部，展示“库存工作台 / 库存查询”和当前部门。
- 使用摘要卡片突出期末数量、库存金额和商品数，销售成本作为辅助指标。
- 商品卡片采用“商品信息—核心数量—金额—流水入口”的固定层级。
- 加载、空数据、失败状态统一使用 `StateView`，下拉刷新保留。

### 库存流水

- 头部与库存查询保持同一标题和部门信息层级。
- 筛选区拆为类型选择和日期区间两层，避免窄屏横向拥挤。
- 流水卡片明确显示入库/出库标识、变动数量、变动后余额、时间和来源备注。
- 保留分页加载、日期筛选、类型筛选、部门切换和状态反馈。

### 库存调整

- 列表采用统一单据卡片，状态、日期、类型、部门和动作层级固定。
- 新增调整作为底部主操作，避让安全区并不遮挡列表内容。
- 编辑抽屉采用与通用表单一致的分区标题、字段间距和提交区。
- 商品明细使用清晰的商品行卡片，突出数量、单位成本和行删除操作。
- 不改变新增、编辑、删除、校验、提交、审批、过账的权限和流程。

## 状态与交互

- 所有列表统一 loading、empty、error、normal 四态。
- 主操作使用蓝色，库存增加使用绿色，库存减少使用橙色/红色，普通辅助信息使用冷灰色。
- 按钮和卡片保持统一圆角、间距、文字字号；操作反馈使用现有 toast 和弹窗。
