# 统一业务模型与配置生命周期实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不扩展 AI、模板市场或 Flowable 引擎范围的前提下，完成低代码统一业务模型、版本并发保护、发布影响报告和费用报销配置生命周期闭环。

**Architecture:** 保留现有 `LcBizConfigDTO` 作为聚合入口，增加模型/版本/精度/时区契约；以配置快照作为不可变历史事实，以草稿作为唯一编辑对象；发布前输出结构化影响报告，发布后绑定配置版本，运行实例不读取未来版本。

**Tech Stack:** Java 17、Spring Boot 4、MyBatis、MySQL、JUnit 5、Vue 3、TypeScript、Element Plus、现有低代码 Runtime 和工作流 API。
