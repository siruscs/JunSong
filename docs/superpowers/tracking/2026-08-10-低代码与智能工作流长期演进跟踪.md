# 低代码与智能工作流长期演进跟踪

> 关联计划：[低代码与智能工作流长期演进开发蓝图](../plans/2026-08-10-低代码与智能工作流长期演进开发蓝图.md)

## 跟踪规则

- 本文件是长期演进的唯一进度台账；每次开发、评审、测试和偏差都必须更新。
- 状态只允许使用：`未开始`、`进行中`、`待验证`、`已完成`、`阻塞`、`暂停`。
- 每个阶段必须同时记录“完成内容”和“验证证据”，没有验证证据不得标记为已完成。
- 发现范围漂移时，先记录偏差和影响，再决定调整计划，不得静默扩大范围。
- 任何 AI、流程、权限、财务和租户相关变更，都必须记录风险评估和回滚方案。

### 数字约束基线

| 类型 | 允许范围 | 存储/计算精度 | 输入与展示格式 | 强制要求 |
|---|---|---|---|---|
| 数量 | 正数、负数、零 | 3 位小数 | `0.000` | `BigDecimal`，禁止 `double`，空值不转零 |
| 金额 | 正数、负数、零 | 2 位小数 | `0.00` | `BigDecimal` + `HALF_UP`，空值不转零 |

该基线适用于低代码字段、业务 DTO、数据库、导入导出、流程变量、报表计算、前端输入和展示。新增字段若未声明为“数量”或“金额”，不得承载对应业务数据。

### 时间约束基线

| 项目 | 规则 |
|---|---|
| 业务时区 | 统一使用北京时间 `Asia/Shanghai` |
| 纯日期 | `YYYY-MM-DD`，例如 `2026-08-04` |
| 日期时间 | `YYYY-MM-DD HH:mm:ss`，例如 `2026-08-04 23:23:23` |
| 页面/导出展示 | 年月日与时分秒之间使用空格，不使用 `T` |
| 适用范围 | 服务端、数据库、流程变量、定时任务、日志、页面、通知、报表、导入导出 |

禁止页面显示 `2026-08-04T23:23:23`、`2026/08/04` 或依赖服务器本地默认时区的未转换时间。

### 开发前五问

每次开始开发前必须在开发日志中回答：

1. 当前主线阶段是什么？
2. 本次任务对应哪个任务编号？
3. 它解决当前阶段哪个退出条件？
4. 完成后用什么测试或演示验证？
5. 本次明确不做哪些相邻需求？

如果其中任何一项无法回答，任务只能保持“未开始”，不得写实现代码。

### 开发后五项回写

每次开发完成后必须回写：

1. 实际完成内容和修改文件；
2. 测试、构建或演示证据；
3. 是否偏离当前主线；
4. 新发现但延期的问题；
5. 下一步仍然指向哪个主线任务。

## 范围变更与延期事项

开发过程中发现的新需求默认不立即实现，必须先记录：

```markdown
### 范围变更申请 · YYYY-MM-DD · 简短标题

- 发现问题：
- 关联阶段/任务：
- 是否阻塞当前退出条件：是 / 否
- 是否影响权限、租户、财务、版本或数据安全：是 / 否
- 现在处理的新增成本：
- 延期到哪个阶段：
- 决定：现在处理 / 放入候选池 / 不处理
- 决定理由：
```

默认决策是“放入候选池”。只有阻塞当前退出条件，或涉及当前任务的数据安全正确性时，才允许扩大范围。

### 当前禁止扩展清单

在阶段 0 退出前，以下事项不得直接进入开发任务：

- AI 自然语言生成、AI Agent 或模型接入；
- 新增与统一业务模型无关的流程节点；
- Flowable 版本升级或替换工作流引擎；
- 建设通用行业低代码市场；
- 全量重构 Vue 页面或更换前端技术栈；
- 与费用报销纵向闭环无关的业务模块扩展；
- 任意脚本、任意 SQL 或未审计自动动作节点。

## 阶段闸门

每个阶段必须依次通过四道闸门：

| 闸门 | 检查内容 | 未通过时的处理 |
|---|---|---|
| G1 主线确认 | 任务是否绑定当前阶段和任务编号 | 退回未开始 |
| G2 设计确认 | 数据、接口、权限、错误和回滚是否明确 | 不得实现 |
| G3 验证确认 | 测试、构建、模拟或演示证据是否存在 | 保持待验证 |
| G4 退出确认 | 阶段退出条件是否全部满足 | 不得进入下一阶段 |

阶段只有通过 G4 才能切换当前阶段；发现的新问题必须进入范围变更或延期事项，不能通过无限增加当前阶段任务来掩盖退出条件未完成。
