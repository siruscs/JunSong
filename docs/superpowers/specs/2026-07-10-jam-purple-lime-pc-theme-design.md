# 酱紫青柠 PC 主题设计规格

## 目标

在现有 `junsong-ui-v3` 主题系统中新增一套可切换的“酱紫青柠”浅色办公主题。主题采用用户参考图中的酱紫 `#3B1B8B` 与青柠 `#9DE805`，呈现克制、硬朗、偏编辑感的企业后台界面，同时保持现有业务结构、路由、组件行为和其他主题不变。

## 设计定位

- 模式：现有产品的保留式视觉改造。
- 用户：需要长时间使用销售、财务、会员和系统管理页面的业务人员。
- 风格：深酱紫品牌框架，冷灰白工作区，青柠高能动作点缀，低圆角，轻阴影，明确边线。
- 设计参数：`DESIGN_VARIANCE 5`、`MOTION_INTENSITY 3`、`VISUAL_DENSITY 7`。
- 主题锁定：浅色主题，不进行页面分区反色，也不在本次范围内增加暗色模式。
- 设计系统：沿用现有 Vue 3、Element Plus 和项目自有 CSS 变量系统，不引入第二套组件库。

## 色彩令牌

### 品牌与动作色

| 语义 | 色值 | 用途 |
| --- | --- | --- |
| 品牌主色 | `#3B1B8B` | 链接、焦点、选中控件、品牌识别 |
| 品牌深色 | `#24104F` | 侧边栏底色、青柠按钮文字 |
| 品牌浅色 | `#7355C6` | 次级品牌状态、柔和高亮 |
| 动作色 | `#9DE805` | 主按钮、当前菜单强调、关键提醒 |
| 动作悬停色 | `#86C900` | 主按钮悬停与按下状态 |
| 动作柔和底色 | `#EEFACF` | 青柠标签、弱提醒背景 |

青柠不得替代成功、警告和危险语义色。Element Plus 原有 `success`、`warning`、`danger` 色保持不变。

### 中性色

| 语义 | 色值 |
| --- | --- |
| 页面背景 | `#F7F7F8` |
| 次级背景 | `#F0EFF3` |
| 表面 | `#FFFFFF` |
| 弱表面 | `#FAFAFB` |
| 边框 | `#DDD9E5` |
| 主文字 | `#211C2B` |
| 次文字 | `#6C6675` |
| 顶栏背景 | `rgba(255, 255, 255, 0.94)` |

## 主题数据模型

扩展现有 `ThemePreset`，增加可选双品牌令牌：

- `action`：主题主动作色。
- `actionHover`：主动作色悬停值。
- `actionText`：动作色背景上的文字色。
- `actionRgb`：动作色 RGB 通道，用于透明背景和焦点层。
- `radiusScale`：主题圆角风格标识，酱紫青柠使用 `compact`。

现有主题未提供这些字段时，全部回退到当前 `primary` 系列，因此新增字段不能改变旧主题视觉。

`applyTheme()` 负责：

1. 写入品牌和动作语义 CSS 变量。
2. 在根元素写入 `data-theme-preset="jam-purple-lime"`。
3. 保持 Element Plus 的 `--el-color-primary` 为酱紫，避免青柠用于链接和焦点时对比不足。
4. 通过独立的动作变量控制主按钮和当前导航状态。

## 组件视觉规则

### 侧边栏

- 背景使用 `#24104F`，子菜单使用略浅的酱紫。
- 默认文字使用浅紫灰，不使用纯白。
- 当前菜单采用透明酱紫底、青柠文字和左侧 3px 青柠强调线。
- 悬停状态使用轻微紫色提亮，不使用大面积青柠背景。
- Logo 文本使用青柠，保持品牌入口清晰。

### 顶栏与工具按钮

- 顶栏保持白色半透明表面，阴影压低为轻微紫灰投影。
- 工具按钮采用 6px 到 8px 低圆角和明确边框。
- 部门切换器不使用胶囊形，改为紧凑矩形。
- 悬停使用淡紫背景，焦点环使用酱紫。

### 主按钮

- 默认背景为青柠 `#9DE805`，文字为深酱紫 `#24104F`。
- 悬停背景为 `#86C900`，不使用外发光。
- 按下状态使用轻微位移或缩放，动画时长不超过 180ms。
- 禁用状态保持可辨识，不使用低对比的浅黄绿文字。

### 卡片、筛选区与表格

- 卡片采用 4px 到 6px 圆角，使用边框表达层级，减少大投影。
- 筛选表单维持现有字段顺序与交互，仅调整焦点、边框和按钮色。
- 表头使用冷灰底，选中行和悬停行使用极淡紫底。
- 分页当前页使用酱紫底；关键动作仍使用青柠。
- 不修改数据密度、列宽、固定列或表格行为。

### 标签与状态

- 业务状态继续使用 Element Plus 原有语义色。
- 非语义的“当前”“推荐”“待处理入口”可以使用青柠柔和底色与酱紫文字。
- 不增加无意义的装饰点或荧光描边。

## 范围

### 包含

- 在 `src/utils/theme.ts` 中增加主题预设和动作色令牌。
- 调整全局主题 CSS，使酱紫青柠主题具有低圆角、硬边线和青柠动作样式。
- 调整侧边栏、顶栏和 Element Plus 全局覆盖。
- 保留现有顶栏主题切换入口，新主题自动出现在选择器中。
- 增加主题契约测试和生产构建验证。

### 不包含

- 不修改默认主题。
- 不重写业务页面布局或业务文案。
- 不改变路由、菜单、权限、表单字段、表格列和分析事件。
- 不新增暗色模式。
- 不引入 Fluent、Carbon、Tailwind 或其他组件系统。
- 不修改成功、警告、危险等业务语义色。

## 兼容与持久化

- 主题 key 为 `jam-purple-lime`。
- 继续使用现有 `localStorage` 与 Cookie 的 `theme-preset` 键。
- 保存过该主题的用户重新登录后继续恢复该主题。
- 无效主题 key 继续回退到当前默认主题 `apple-silver`。
- 所有旧主题缺少动作令牌时必须保持原样。

## 可访问性

- 青柠按钮必须使用深酱紫文字，不允许白字。
- 普通正文和表单标签满足 WCAG AA 4.5:1。
- 大号关键数字满足至少 3:1。
- 键盘焦点不只依赖颜色，应保留可见的边框或焦点环。
- 动画仅使用短时悬停和按下反馈，并尊重 `prefers-reduced-motion`。

## 测试与验收

### 自动测试

- 新主题存在且 key、名称、主色、动作色正确。
- `getThemePreset('jam-purple-lime')` 返回正确预设。
- `applyTheme()` 写入品牌色、动作色和根主题属性。
- 旧主题缺少动作字段时正确回退。
- 主题保存和恢复逻辑保持兼容。
- `npm run build` 成功。

### 视觉验收

- 侧边栏、顶栏、按钮、输入框、筛选区、卡片、表格、分页和弹窗均使用一致令牌。
- 主按钮青柠底配深酱紫文字，桌面端文字不换行。
- 全站只有一套浅色主题表达，没有中途反色。
- 圆角尺度一致，卡片不超过 6px，交互控件不超过 8px。
- 成功、警告和危险状态未被青柠覆盖。
- 主题切换后刷新页面仍保持选择。
- 至少检查 1280px 与 1440px 两个常用办公宽度。

## 失败处理

- 新增字段全部为可选字段，避免旧主题或存量 Cookie 导致运行错误。
- 若主题 key 无法解析，沿用现有默认主题回退行为。
- CSS 覆盖必须限定在 `data-theme-preset="jam-purple-lime"` 下，避免污染其他主题。
