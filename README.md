# JunSong 运营小程序

基于 uni-app + Vue 3 的微信小程序工程，覆盖后台前端中的会员服务和财务管理功能。

## 功能范围

会员服务：

- 会员信息
- 积分物品
- 积分规则
- 积分记录
- 积分兑换
- 秒杀活动
- 秒杀记录

财务管理：

- 费用记录
- 借支记录
- 商品管理
- 供应商
- 进货单
- 销售记录
- 投资人返款
- 投资人管理
- 投资款记录
- 店面分润配置
- 核算周期
- 分润结转
- 成本核算

通用能力：

- 列表分页查询
- 新增、编辑、详情、删除
- 状态/日期/金额等表单控件
- 费用核销、积分兑换领取、秒杀领取、关闭秒杀活动
- 销售记录添加缴款
- 成本核算预览与生成
- 网关地址和 Token 本地配置

## 运行

```bash
npm install
npm run dev:mp-weixin
```

## 构建

```bash
npm run build:mp-weixin
```

构建产物位于 `dist/build/mp-weixin`，可使用微信开发者工具打开。

## 接口配置

小程序首页进入“设置”，填写后端网关地址和认证 Token。默认网关地址为：

```text
http://localhost:8080
```

生产环境需要替换为可被微信小程序访问且已配置合法域名的 HTTPS 网关地址。
