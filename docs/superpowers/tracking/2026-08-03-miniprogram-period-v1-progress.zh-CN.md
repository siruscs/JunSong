## 已知约束

1. 不覆盖 `main` 上已有财务和库存提交。
2. V1.0、V1.1、V1.2 均在本分支，但严格按阶段提交和门禁推进；字典缓存属于 V1.0，不再归入 V1.1。
3. 后端权限、租户和部门范围是最终边界，前端隐藏不代替服务端校验。
4. 周期净利必须使用实际缴款，不使用销售额作为收入。
5. 小程序子仓库必须先独立提交，再更新父仓库 gitlink。
6. FILE 服务启动修复单独记录，不能用“容器重启成功”替代应用真正启动成功；必须看到 Spring Boot started、注册成功和健康检查通过。
