# 库存数量与成本计算公式说明

本文档记录库存报表、库存成本层、价值报表使用的核心计算口径，便于后续对账、培训和运维排查。

## 1. 基础数据来源

| 数据 | 来源表 | 说明 |
|---|---|---|
| 库存流水 | `fin_stock_ledger` | 记录采购入库、销售出库、冲销等数量变化 |
| 当前库存结存 | `fin_stock_position` | 按租户、门店、商品保存当前数量 |
| 成本层 | `fin_stock_cost_layer` | 按租户、门店、商品保存当前移动加权平均成本、成本数量、库存金额 |
| 成本流水 | `fin_stock_cost_ledger` | 记录每笔采购、销售、冲销、调整产生的成本金额 |
| 采购金额 | `fin_purchase_detail.amount` | 采购入库成本金额来源 |
| 销售收入 | `fin_sale_record.sale_amount` | 销售收入来源，不含赠品收入 |

## 2. 库存数量公式

库存结存数量来自库存流水的累计净额：

```text
库存结存数量 = 采购入库数量 - 采购冲销数量 - 销售出库数量 + 销售冲销数量
```

对应 `fin_stock_ledger.change_type`：

| 类型 | 数量方向 | 说明 |
|---|---:|---|
| `PURCHASE_IN` | `+` | 采购入库 |
| `PURCHASE_REVERSE` | `-` | 采购冲销/退回 |
| `SALE_OUT` | `-` | 销售出库 |
| `SALE_REVERSE` | `+` | 销售冲销/删除销售单回补 |

销售出库数量口径：

```text
销售出库数量 = 销售数量 + 销售赠品数量
```

采购入库数量口径：

```text
采购入库数量 = 采购收费数量 + 采购赠品数量
```

赠品会影响实物库存数量。

## 3. 移动加权平均成本

移动加权平均成本保存在 `fin_stock_cost_layer.avg_unit_cost`。

采购入库时重新计算平均成本：

```text
新库存数量 = 原库存数量 + 本次入库数量
新库存金额 = 原库存金额 + 本次入库金额
新平均成本 = 新库存金额 / 新库存数量
```

如果新库存数量为 0：

```text
新平均成本 = 0
```

系统金额精度：

```text
单位成本：保留 6 位小数
金额：保留 2 位小数
舍入：HALF_UP
```

## 4. 采购赠品成本口径

采购赠品计入库存数量，但不计入采购金额。

因此赠品会摊薄平均成本：

```text
入库数量 = 收费数量 + 赠品数量
入库金额 = 收费采购金额
入库单位成本 = 入库金额 / 入库数量
```

示例：

```text
采购收费数量：100
采购赠品数量：20
采购金额：2700

入库数量 = 100 + 20 = 120
入库金额 = 2700
入库单位成本 = 2700 / 120 = 22.500000
```

## 5. 销售出库成本

销售出库时，不重新计算平均成本，而是使用出库当时的移动加权平均成本。

```text
销售成本 = 销售出库数量 × 出库当时平均成本
```

销售出库后：

```text
新库存数量 = 原库存数量 - 销售出库数量
新库存金额 = 原库存金额 - 销售成本
平均成本保持不变
```

销售出库时会固化单位成本：

```text
fin_stock_ledger.unit_cost = 出库当时平均成本
```

同时写入成本流水：

```text
fin_stock_cost_ledger.source_type = SALE
fin_stock_cost_ledger.cost_change_type = COST_OUT
fin_stock_cost_ledger.quantity = -销售出库数量
fin_stock_cost_ledger.unit_cost = 出库当时平均成本
fin_stock_cost_ledger.amount = 销售成本
```

## 6. 销售赠品成本口径

销售赠品不产生销售收入，但会消耗库存并计入销售成本。

```text
销售出库数量 = 销售收费数量 + 销售赠品数量
销售收入 = 销售收费金额
销售成本 = 销售出库数量 × 出库当时平均成本
```

示例：

```text
销售收费数量：10
销售赠品数量：2
出库当时平均成本：27
销售收入：1000

销售出库数量 = 10 + 2 = 12
销售成本 = 12 × 27 = 324
毛利 = 1000 - 324 = 676
```

## 7. 销售冲销成本

销售冲销或删除销售单时，不能使用当前平均成本回算。

必须使用原销售出库时固化的单位成本：

```text
销售冲销回补金额 = 冲销数量 × 原 SALE_OUT.unit_cost
```

成本流水口径：

```text
fin_stock_cost_ledger.source_type = SALE
fin_stock_cost_ledger.cost_change_type = COST_REVERSE_IN
fin_stock_cost_ledger.quantity = 冲销数量
fin_stock_cost_ledger.unit_cost = 原销售出库固化单位成本
fin_stock_cost_ledger.amount = 销售冲销回补金额
```

冲销后会重新计算平均成本：

```text
新库存数量 = 原库存数量 + 冲销数量
新库存金额 = 原库存金额 + 销售冲销回补金额
新平均成本 = 新库存金额 / 新库存数量
```

## 8. 采购冲销成本

采购冲销按当前成本层平均成本扣减库存金额：

```text
采购冲销金额 = 冲销数量 × 当前平均成本
```

冲销后：

```text
新库存数量 = 原库存数量 - 冲销数量
新库存金额 = 原库存金额 - 采购冲销金额
新平均成本 = 新库存金额 / 新库存数量
```

成本流水口径：

```text
fin_stock_cost_ledger.source_type = PURCHASE
fin_stock_cost_ledger.cost_change_type = COST_REVERSE_OUT
```

## 9. 库存价值报表公式

价值报表金额来自 `fin_stock_cost_ledger`。

### 9.1 期初金额

```text
期初金额 =
  查询开始日期之前所有 COST_IN
+ 查询开始日期之前所有 COST_REVERSE_IN
- 查询开始日期之前所有 COST_OUT
- 查询开始日期之前所有 COST_REVERSE_OUT
+ 查询开始日期之前所有 COST_ADJUST
```

### 9.2 本期入库金额

```text
本期入库金额 =
  本期 COST_IN
- 本期 COST_REVERSE_OUT
```

### 9.3 本期销售成本

```text
本期销售成本 =
  本期 COST_OUT
- 本期 COST_REVERSE_IN
```

### 9.4 本期成本调整

```text
本期成本调整 = 本期 COST_ADJUST
```

### 9.5 期末金额

```text
期末金额 = 期初金额 + 本期入库金额 - 本期销售成本 + 本期成本调整
```

### 9.6 销售收入

销售收入来自销售单金额：

```text
销售收入 = SUM(fin_sale_record.sale_amount)
```

销售赠品不计收入。

### 9.7 毛利

```text
毛利 = 销售收入 - 销售成本
```

```text
毛利率 = 毛利 / 销售收入 × 100%
```

当销售收入为 0 时，毛利率不应强行计算。

## 10. 成本层门禁

价值报表使用 `costReady` 门禁。

只有满足以下条件时，才展示金额和毛利：

```text
当前租户/授权门店范围内存在成本层
并且
所有有库存流水的门店商品组合都有成本层
```

如果有库存流水但没有成本层：

```text
costReady = false
```

前端会提示“成本层未初始化”，并隐藏金额和毛利，避免把未计算成本误显示为 0。

## 11. 负库存和先销售后采购

如果历史数据存在先销售后采购，或销售数量大于采购数量，会产生负库存。

这种情况下系统仍会按历史流水顺序计算成本，但结果需要业务对账解释：

```text
先销售、当时没有平均成本：销售成本可能为 0
后采购：后续入库会形成成本金额，但不能自动改写历史销售成本
负库存：库存数量和库存金额可能出现异常组合
```

因此，价值报表能打开不代表历史库存完全健康。负库存商品需要单独做库存数量对账。

## 12. 常见对账检查

### 12.1 库存数量是否一致

```text
fin_stock_position.quantity
=
SUM(fin_stock_ledger.change_quantity)
```

按租户、门店、商品分组检查。

### 12.2 成本层数量是否一致

```text
fin_stock_cost_layer.stock_quantity
=
fin_stock_position.quantity
```

按租户、门店、商品检查。

### 12.3 销售出库是否已固化成本

```text
fin_stock_ledger.change_type = SALE_OUT
且 unit_cost 不应为空
```

### 12.4 有库存流水是否都有成本层

```text
每个 tenant_id + dept_id + product_id 的库存流水组合
都应存在对应 fin_stock_cost_layer
```

否则价值报表应保持 `costReady=false`。

## 13. 普通用户使用说明（店长版）

本节面向店长、仓库负责人和日常报表使用人员。系统会根据已经保存的采购、销售和冲销记录自动计算库存，不需要用户手工套用公式。

### 13.1 数量报表怎么看

- **期初库存**：统计开始日期时，门店已经有的库存数量。
- **采购入库**：期间内实际入库的收费商品和赠品数量。
- **销售出库**：期间内实际销售发出的收费商品和赠品数量。
- **期末库存**：截至统计结束日期，系统计算出的剩余库存数量。

最简单的理解是：

```text
期末库存 = 期初库存 + 入库数量 - 出库数量
```

退货、冲销或删除已生效单据后，系统会按对应记录回补或扣减库存。数量报表反映的是系统中已保存并生效的业务记录。

### 13.2 价值报表怎么看

- **库存金额**：当前剩余商品按系统成本计算出的金额，不是销售价。
- **销售成本**：卖出商品时，这些商品当时对应的采购成本。
- **销售收入**：销售单上的实际收费金额，赠品不产生收入。
- **毛利**：销售收入减去销售成本。

因此，销售价格高于成本不等于所有销售都有相同毛利；不同批次采购价格不同，系统会按当时的平均成本计算。

### 13.3 为什么赠品也会影响结果

赠品是实际发出的商品，所以会影响库存数量和销售成本：

- 采购赠品会增加库存数量，但没有单独采购金额，因此会降低平均成本。
- 销售赠品会减少库存数量，并计入销售成本，但不计入销售收入。

例如，采购 100 件并赠送 20 件，系统库存增加 120 件；销售 10 件并赠送 2 件，系统库存减少 12 件。

### 13.4 看到“成本层未初始化”怎么办

这不是店长需要手工录入的内容，而是系统尚未完成这批历史库存的成本计算。出现提示时，价值报表会暂不显示金额和毛利，避免把“尚未计算”误认为“金额为 0”。

店长应先确认：

1. 采购入库单是否已经审核并保存采购金额。
2. 销售单是否已经正常保存并产生出库记录。
3. 是否有历史单据正在补录、冲销或等待后台处理。

确认业务单据完整后，由系统管理员或财务人员执行成本初始化，再重新打开价值报表。普通用户不需要直接修改成本数据。

### 13.5 发现库存数量不对时怎么处理

先查看该门店和商品的库存流水，重点核对采购入库、销售出库、退货和冲销记录。常见原因包括：

- 采购或销售单据漏录、重复录入；
- 单据已删除或冲销，但对应业务没有完整回补；
- 历史上先销售后采购，导致当时出现负库存；
- 赠品数量没有纳入人工核对。

请先通过业务单据修正来源记录，再由系统重新计算。不要为了让期末数量看起来正确而直接修改库存余额。

### 13.6 什么时候需要联系管理员

遇到以下情况请保留门店、商品、日期和单据编号，交给系统管理员或财务人员处理：

- 流水中出现销售出库，但找不到对应销售单；
- 销售出库数量与实际销售数量不一致；
- 期末库存出现负数；
- 价值报表提示成本未初始化；
- 同一商品的库存数量、库存金额或毛利明显异常。
